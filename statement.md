# Sports Management Program — Project Statement

## Problem Statement
Managing player details and scores manually can make it difficult to find records, keep scores current, and identify the top scorer. This project provides a simple console-based system for organizing player information and scores.

## Scope of the Project
The program manages player records during a single run. It supports adding, viewing, searching, and deleting players, updating a player’s score, and displaying the highest scorer. Data is kept in memory and is not saved after the program closes.

## Target Users
This program is intended for small sports teams, coaches, or organizers who need a basic way to track player details and scores.

## High-Level Features
- Add player name, sport, age, and score
- View all player records
- Search for a player by name
- Update a player’s score
- Display the highest scorer
- Delete a player record
- Navigate the features through a simple menu
